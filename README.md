# Glansverket Bilvård

Glansverket Bilvård är en webbplats för ett bilvårdsföretag.
Syftet med webbplatsen är att presentera företagets behandlingar,
beskriva verksamheten och göra det enkelt för besökare att ta kontakt.

## Webbplats

Besök webbplatsen här:
https://ramikassab-spec.github.io/glansverket-bilvard/

## Sidor

- Startsida – presentation av företaget och dess behandlingar.
- Tjänster – information om tillgängliga bilvårdsbehandlingar.
- Om oss – information om företaget och dess värderingar.
- Kontakt – kontaktformulär för förfrågningar.

## Tekniker

Webbplatsen är byggd med:

- HTML
- CSS
- JavaScript

Webbplatsen är responsiv och anpassad för både datorer
och mobila enheter.

## Publicering

Webbplatsen publiceras med GitHub Pages.
